# Salary System

Sistema simples desenvolvido em Java para gerenciamento universitário,
utilizando conceitos de Programação Orientada a Objetos.

## 📌 Funcionalidades
- Cadastro de alunos
- Cadastro de disciplinas
- Matrícula de alunos
- Organização em camadas (model, service)

## 🛠️ Tecnologias
- Java
- IntelliJ IDEA
- Git e GitHub

## ▶️ Como executar
1. Abra o projeto no IntelliJ IDEA
2. Execute a classe `Main`
