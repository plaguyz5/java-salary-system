# Java Salary System

Sistema em Java para gerenciamento e cálculo de salários, desenvolvido com foco em Programação Orientada a Objetos (POO).

## Funcionalidades
- Cadastro de funcionários
- Cálculo de salários
- Estrutura organizada em camadas
- Execução via terminal

## Estrutura do Projeto
- `model` — entidades do sistema
- `service` — regras de negócio
- `Main` — ponto de entrada da aplicação

## Tecnologias Utilizadas
- Java
- Programação Orientada a Objetos (POO)
- Git e GitHub

## Objetivo
Projeto desenvolvido para fins acadêmicos e construção de portfólio.
